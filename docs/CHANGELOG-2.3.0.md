# IRIDIS 2.3.0 更新说明

## ① GUI 智能体借鉴 Mika 升级

参考开源项目 Mika（github.com/wangzan101/mika，Apache-2.0，0.1.13 / 688f59d）。只移植不需要 shell/root/虚拟屏的部分；隐藏虚拟屏模式未做。规则不变：所有模型同一套提示词规则、模型直接给 0–1000 坐标（不吸附）、界面元素只作参考、是否完成由模型判断。

- **滚动动作 scroll**：`{"action":"scroll","direction":"down"}` / `do(action="Scroll", direction="down")`，方向 = 想看的内容方向。先用列表自身的无障碍滚动（精确、不甩），不行再用滑动手势；可加坐标指定哪个列表。滚动没让画面变化时提示「可能到头了」。
- **滚动直到找到**：加 `until="文字"`，智能体自己连续滚动（最多 8 次，不再每次问模型），找到就把位置告诉模型（仅参考，由模型自己点），到底没找到也如实告诉它。省下大量模型步骤。
- **长按 / 滑动时长**：长按可带时长（`duration="2 seconds"` / `"time": 2`），滑动可带时长。
- **界面元素精简**：同位置重复的文字只列一次；超过 60 个时优先保留可点/可输入的元素，再按屏幕顺序补文字；空输入框显示占位提示 `hint="搜索"`；显示 selected 状态。
- **树不全自动 OCR**：除了文字太少，按钮大多没有文字（Mika 的「unlabeled controls」判断）时也启用 OCR 兜底。
- **屏幕诊断**（移植 Mika ScreenDiagnosis）：验证码/支付/密码/短信验证码页面提示模型交给用户；读不到元素时提示看截图或等待。
- **应用无响应 / 崩溃**：识别系统「没有响应」「屡次停止运行」对话框，自动点「等待」/「关闭应用」（每次任务最多 2 次，不占模型步骤），崩溃后提示模型重新打开。
- **卡住恢复**（移植 Mika StuckAdvice）：第二次被判卡住时建议先 Back / Home + 重新打开应用，再不行就如实结束；同一应用里同一段文字输入 3 次会提醒换关键词或入口。
- **误入其他应用**：非打开/返回/桌面动作后前台应用变了（不含从桌面进入），提醒模型需要时返回。
- **步骤记忆**：历史只发最近 8 步，更早的步骤压成一行（到过的应用、输入过的文字、失败与无效果次数）。
- **完成核对**：上一步失败或画面没变时模型说「完成」，会请它看当前截图再确认一次（每次任务最多一次，仍由模型决定）。
- 许可：新增 Mika（Apache-2.0）条目与 notice-mika.txt；移植的文件保留出处与版权说明。

风险：均未真机验证；无障碍滚动在部分应用（WebView、Flutter、自绘列表）可能返回成功但不动，此时靠「画面没变化」提示和下一次的手势兜底；ANR 对话框按文字识别，个别 ROM 文案不同会退回由模型处理。

## ② MCP（远程服务）

安卓没有终端，按项目规则不启动任何本地进程（无 stdio），只连接**远程** MCP 服务器。

- **设置 › 智能体 › MCP 服务**：添加服务（名称、地址、可选令牌、可选自定义请求头），保存后自动测试连接并显示工具数；每个服务可启用/停用、编辑、删除，每个工具单独开关；已「总是允许」的服务可改回询问。
- **连接方式**：优先 Streamable HTTP（2025-03-26 及以后规范：POST、JSON 或 SSE 回应、Mcp-Session-Id、MCP-Protocol-Version）；服务器拒绝时自动改用旧版 HTTP+SSE。JSON-RPC initialize / tools/list（支持分页）/ tools/call。连接 10 秒、回应 30 秒（工具调用 60 秒）超时；断流或会话过期会自动重连一次再试。
- **安全**：令牌和请求头用 Android Keystore（AES-GCM）加密保存在本机；http 地址会提示不加密。每个服务第一次调用工具前弹出确认（允许一次 / 总是允许 / 拒绝），允许一次后本次运行内不再询问。
- **给模型用**：启用的 MCP 工具与 9 个内置工具一起提供给本地模型和在线模型，名称为 `mcp_<服务>_<工具>`，说明截短到 100 字，参数结构压成一行签名（嵌套参数写成 `opts.lang`，调用时自动还原、数字/布尔自动转换）。最多注入 20 个，超过时设置页提示关掉不常用的。
- **结果与错误**：工具结果显示在原有步骤卡片里；连接失败、调用失败、服务器返回错误都会记入「最近提示」。

风险：未真机验证；工具列表来自上次「测试连接」的缓存（服务器新增工具需再点一次）；只支持令牌/请求头鉴权，不支持 OAuth 登录流程；不支持服务器主动发起的请求（sampling/elicitation）和资源、提示词功能。

## ③ 本地翻译

- **消息翻译**：长按自己的消息，或点回复下方「⋯」，选「翻译」。译文显示在消息下方，可「显示原文 / 显示译文」切换、复制译文、关闭；回复只翻译正文，不含思考内容。
- **输入框翻译**：输入框右上「+」里选「翻译（自动 中↔英）」「译成中文」「译成英文」，译文直接替换草稿（流式出现），可点 × 撤销翻译恢复原文，确认后再发送。
- **自动语言**：默认中↔英——中文译成英文，其他译成中文（按汉字与字母比例判断）。
- **引擎**：默认用当前已加载的模型翻译：单独的简短翻译提示词，不带工具、记忆、知识库和对话上下文，关闭思考并把模型输出里的思考内容去掉，流式显示。没有加载模型时用离线引擎。
- **离线引擎**：Mozilla Bergamot（Firefox 翻译同款，bergamot-translator + Marian，MPL-2.0），本机 arm64 原生库约 7.8 MB；模型按方向下载：中→英（tiny）约 36 MB、英→中（base）约 51 MB，从 Hugging Face（经 魔搭 / hf-mirror / HF 下载源自动切换）获取。离线引擎按段落逐段翻译、逐段显示。不使用 ML Kit（需要谷歌服务器）。
- **设置 › 语音与翻译**（原「语音」页）新增「翻译」：译成（自动 / 中文 / 英文）、翻译引擎（自动 / 当前模型 / 离线），以及两个离线翻译包的下载 / 删除。下载模型页「推荐」新增「翻译」分组。
- 没有可用引擎时提示「请先加载一个模型」（或提示下载对应方向的离线翻译包）。
- 许可：新增 bergamot-translator（MPL-2.0）、Marian（MIT）、ruy / SentencePiece / ssplit（Apache-2.0）、PCRE2（BSD）、yaml-cpp（MIT）、zlib、Firefox Translations 模型（MPL-2.0）条目。

风险：离线引擎与翻译 UI 均未真机验证（沙盒不能运行安卓原生库）；离线库按 armv8.2-a+dotprod 编译，2018 年以前的老芯片可能无法加载（会自动退回「请先加载一个模型」）；用模型翻译时如果对话正在生成，翻译会排队等它结束。
