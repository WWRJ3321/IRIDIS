## 通用工具箱方向（用户 2026-11-17 定方向）
核心：升级 sd.cpp 到新版（它按张量名自动识别架构，已覆盖 SD1.x/2.x、SDXL、SD3.5、FLUX.1/2/3 Klein、Chroma、Z-Image、Qwen-Image(2.1)、Anima、ERNIE-Image 等），导入改成「主模型 + 可选文本编码器 + 可选 VAE」，不再按牌子列预设。
手机候选（12GB 级内存，量化 Q4/Q8；许可仅作参考，未逐个核实）：
- SD1.5 / LCM、SDXL-Lightning、SSD-1B：小、快，OpenRAIL 系（有使用限制条款，可商用）
- Z-Image-Turbo 6B：Apache-2.0，现已支持
- FLUX.2 Klein 4B：Apache-2.0，现已支持
- Bonsai Image 4B（1-bit/三值，基于 FLUX.2 Klein）：Apache-2.0，需确认 sd.cpp 是否支持其低位权重
- FLUX.3 Klein 5.55B：社区许可，年收入 <500 万美元可商用
- SD3.5 Medium 2.5B：Stability 社区许可（有条件）
- Qwen-Image-2.1 7B、FLUX.2 Klein 9B、Anima：非商用，只能用户自己导入
需适配：新架构的文本编码器/VAE 配对提示、内存预估与拒绝过大模型、采样器默认值（步数/CFG）按架构自动填、NPU 路线（sdq）单独评估。
