# 2.1.9（vc187，2026-10-23）

feat/files（基于 release/2.1.8）：新增「文件」页（part A）与可选「档案模式」（part B）。

## 「文件」页
- 侧栏「文件」进入新页面，管理整个 下载/IRIDIS：面包屑导航，名称 / 大小 / 修改时间列表，按名称 / 时间 / 大小排序（再点切换升降序）。
- 操作：用其他应用打开（FileProvider）、分享、重命名、删除（确认）、新建文件夹；小文本与 Markdown 在应用内预览（复用聊天 Markdown 渲染）。
- 系统文件夹（模型 / 语音 / 技能 / 知识库 / 配置 / 工作区）固定置顶，带「系统」角标，不能重命名 / 删除；models/、voice/ 内文件改名或删除时额外提示。
- 路径限制在 下载/IRIDIS 内（拒绝 `..` 和指向外部的符号链接，删除不跟随符号链接）；不新增权限，未开启全部文件访问时显示原有引导。

## 档案模式（可选，顶栏开关，默认关闭）
- 新设置 `fileViewStyle`：LIST（默认）/ ARCHIVE。
- 伪 3D 档案卡：半透明磨砂卡片（细描边、内高光线、顶部彩色标签、等宽编号 `ARC-0042`、名称、类型标签、大小 / 时间），颜色全部取自当前配色，适配所有主题与深色模式。
- 竖向卡组：聚焦卡正对、放大；相邻卡按距离缩小、变淡、倾斜（graphicsLayer rotationX / rotationY + cameraDistance）、阴影变浅。上下滑动 / 甩动浏览并吸附到卡片；超过 5 项时首尾循环，否则到头有回弹。停稳后选中卡上浮，相邻卡依次波动。
- 顶部 HUD：当前文件夹名 + 项数（每位数字独立滚动）、路径标签（可点返回上级）、聚焦卡编号滚动。
- 点按聚焦卡：文件夹 → 当前卡片后退下沉，新文件夹卡片依次升起；文件 → 「解密」面板：斜向扫光由磨砂到清晰，显示名称、类型、大小、修改时间、路径，可预览（文本 / Markdown，复用应用内预览）、打开、分享、重命名、删除。长按任意卡片 = 列表的「⋯」菜单。系统文件夹保留角标与保护。
- 系统「移除动画」开启时不倾斜、无波动、无解密扫光。只组合可见的最多 7 张卡，逐帧数值只在 graphicsLayer / 绘制阶段读取；解密模糊仅在 API 31+ 且视觉效果允许模糊时使用（模糊半径分 5 档缓存），否则用半透明遮罩。
- 纯数学（循环下标、深度 / 缩放 / 旋转曲线、波动与升降、扫光遮罩多边形、编号格式、数字拆分）在 `ArchiveMath`，有 JVM 单测。动画规格加在 `IrisMotion`（ArchiveSnap、ARCHIVE_* 时长、progress()）。
- 设计灵感：LBEILC/RhineLabUI（MIT，Copyright (c) 2026 LBEILC）。未复制任何代码、字体、图标、音频或游戏名称 / 标志；纯 Compose，无 WebView / WebGL，无新依赖。「关于 › 开源组件」与许可证全文中增加了「设计灵感」致谢。

## 档案模式：打开转场与详情页重做（同版本 2.1.9 / vc187）
- 反馈：「弹出的方式很有问题，视觉效果对不上」。旧详情是整屏淡入的面板，与参考（RhineLabUI 的镜头前推 + 解密）不符。只改「档案」的打开转场与详情页；阵列浏览、卡片、列表不变。
- 转场（共享元素式，一条 1300ms 线性时间轴 `IrisMotion.ARCHIVE_OPEN_MS`，各阶段用 `ProgressEasing` 自行缓动）：
  - 推近（0–40%）：起点 = 选中档案板竖起时的宽面在屏幕上的四角（`SlabField.selectedFace`），终点 = 详情布局里玻璃板的矩形；玻璃板按最终布局排好，绘制时用 `Matrix.setPolyToPoly` 把矩形映射到两者逐角插值的四边形（透视连续变形）。阵列里这块板同时隐藏（`build(hideSelected)`）。背景阵列以该板为中心放大 1.3 倍、透明度降到 0.6、分 5 档模糊（API 31+ 且允许模糊时），再盖一层背景色薄纱——不是黑色遮罩、不是底部 sheet、不是淡入弹窗。HUD 随推近淡出。
  - 扫描（38–68%）：一条左下→右上走向的细对角线从左上角扫到右下角（两端方点、两角标记），扫过的区域显出清晰的标签牌与主视觉，未扫过处只有虚化淡影（`scanPolygon` 裁剪）。
  - 解密（50–96%）：信息区在推近时已带着黑条淡入；标题、类型、四个字段、摘要逐行错峰把黑条自左向右收回（按每行文字实际宽度画条，多行文字行间再错开）；较长的标题先露出前 2–3 个字停顿一下再全部出现。
  - 关闭（720ms，`ARCHIVE_CLOSE_MS`）：信息区淡出 → 玻璃板内容淡出并缩回阵列原位 → 背景清晰；中途关闭从当前状态接着反向。系统返回键、左上「← 档案总览 [ESC]」、实体键盘 Esc 都可关闭。移除动画：直接到终态，无推近 / 扫描 / 黑条。
- 详情页（竖屏：玻璃板在上约 36% 高，信息可滚动，底部按钮固定；横屏左右分栏）：
  - 玻璃板：暖白磨砂（深色模式为石墨上的淡玻璃），细边框、内框线、左侧导槽线、四角螺钉、右下斜纹与小圆环。左上标签牌（所在文件夹名或「IRIDIS」+ INFO + 大号 NO.xxx）；左下大号 NO.xxx、「INTERNAL DATABASE · IRIDIS 存储」、系统目录标记。主视觉：图片 = 缩略图嵌在内框里（带裁切角标）；文本 / Markdown = 前 10 行等宽「打印档案」带行号；文件夹 = 抽屉格显示前几个子项名；其他 = 大号扩展名字形（如 .GGUF）配细线圆环、刻度与一段铜色弧。无新素材 / 字体 / 依赖。
  - 信息区：FILE F-001 / REFERENCE AREA；文件名大标题（最多两行省略）；中文类型（模型权重、语音模型、Markdown 文档、图片、文件夹……）+ 所在目录小标签；粗分隔线；类型 / 大小 / 修改时间 / 状态（▪ 可编辑 / ▪ 受保护）。
  - 01 概述：自动摘要（类型、大小、文本行数、图片分辨率、文件夹子项数与前几项、所在系统目录；models / voice 内的文件提示改名或删除会影响模型加载；系统目录说明不能改删），文本文件附前几行。02 属性：完整路径（等宽、可选中、一键复制）、扩展名、MIME、所在目录、字节数、修改时间、系统保护。03 操作：打开（应用内阅读或交给其他应用）、用其他应用打开、分享、重命名、删除——复用 FilesActions 与原有确认 / 保护逻辑，系统目录禁用并写明原因。
  - 底部：深色长条「+ 打开文件 · OPEN」（文件夹为「+ 进入文件夹 · ENTER」）与「分享 ↓」；最底一行「▪ IRIDIS · 本地存储」、序号「001 / 040」（在当前分类中的位置）、时钟。
- 点按竖起的档案板现在对文件夹也先打开详情；HUD 上的「进入 ACCESS FOLDER →」仍直接进入文件夹。
- 读取（缩略图、前几行与行数、文件夹子项）全部在 IO 线程，经 `FilesPaths.resolve` / `FilesIo.list` 限制在 下载/IRIDIS 内。
- 几何与时序（阶段进度、四边形插值、景深参数、扫描多边形 / 线段、标题停顿、行内错峰、中文类型名、字形、序号、行数、摘要）在 `ArchiveMath`，新增 ArchiveOpenTest。

## GUI 智能体：聊天里直接说就操控手机（feat/gui-agent，仅 test/2.1.9-gui，实验）
