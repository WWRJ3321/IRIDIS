# 2.1.9（vc187，2026-10-23）

feat/files（基于 release/2.1.8）：新增「文件」页（part A）与可选「档案模式」（part B）。

## 「文件」页
- 侧栏「文件」进入新页面，管理整个 下载/IRIDIS：面包屑导航，名称 / 大小 / 修改时间列表，按名称 / 时间 / 大小排序（再点切换升降序）。
- 操作：用其他应用打开（FileProvider）、分享、重命名、删除（确认）、新建文件夹；小文本与 Markdown 在应用内预览（复用聊天 Markdown 渲染）。
- 系统文件夹（模型 / 语音 / 技能 / 知识库 / 配置 / 工作区）固定置顶，带「系统」角标，不能重命名 / 删除；models/、voice/ 内文件改名或删除时额外提示。
- 路径限制在 下载/IRIDIS 内（拒绝 `..` 和指向外部的符号链接，删除不跟随符号链接）；不新增权限，未开启全部文件访问时显示原有引导。

## 档案模式（可选，顶栏开关，默认关闭）
- 新设置 `fileViewStyle`：LIST（默认）/ ARCHIVE。
- 伪 3D 档案卡：半透明磨砂卡片（细描边、内高光线、顶部彩色标签、等宽编号 `ARC-0042`、名称、类型标签、大小 / 时间），颜色全部取自当前配色，适配所有主题与深色模式。
- 竖向卡组：聚焦卡正对、放大；相邻卡按距离缩小、变淡、倾斜（graphicsLayer rotationX / rotationY + cameraDistance）、阴影变浅。上下滑动 / 甩动浏览并吸附到卡片；超过 5 项时首尾循环，否则到头有回弹。停稳后选中卡上浮，相邻卡依次波动。
- 顶部 HUD：当前文件夹名 + 项数（每位数字独立滚动）、路径标签（可点返回上级）、聚焦卡编号滚动。
- 点按聚焦卡：文件夹 → 当前卡片后退下沉，新文件夹卡片依次升起；文件 → 「解密」面板：斜向扫光由磨砂到清晰，显示名称、类型、大小、修改时间、路径，可预览（文本 / Markdown，复用应用内预览）、打开、分享、重命名、删除。长按任意卡片 = 列表的「⋯」菜单。系统文件夹保留角标与保护。
- 系统「移除动画」开启时不倾斜、无波动、无解密扫光。只组合可见的最多 7 张卡，逐帧数值只在 graphicsLayer / 绘制阶段读取；解密模糊仅在 API 31+ 且视觉效果允许模糊时使用（模糊半径分 5 档缓存），否则用半透明遮罩。
- 纯数学（循环下标、深度 / 缩放 / 旋转曲线、波动与升降、扫光遮罩多边形、编号格式、数字拆分）在 `ArchiveMath`，有 JVM 单测。动画规格加在 `IrisMotion`（ArchiveSnap、ARCHIVE_* 时长、progress()）。
- 设计灵感：LBEILC/RhineLabUI（MIT，Copyright (c) 2026 LBEILC）。未复制任何代码、字体、图标、音频或游戏名称 / 标志；纯 Compose，无 WebView / WebGL，无新依赖。「关于 › 开源组件」与许可证全文中增加了「设计灵感」致谢。

## 档案模式 重做（同版本 2.1.9 / vc187）
- 真机反馈（Redmi K90）：旧卡组「效果完全不对」——卡片挤在下半屏、后方卡片文字透出。按 LBEILC/RhineLabUI 参考图重做。
- 顶栏开关改为小菜单：列表 / 档案 / 卡片；`fileViewStyle` 接受 LIST / ARCHIVE / CARDS（默认仍 LIST）。
- 「档案」（ArchiveFileView）：全屏等距视角的档案槽阵列（薄长方体，顶面 / 侧面 / 端面三档明暗、顶面高光棱、端部小黑点、地面接触阴影、顶部雾化），铺满并裁切到屏幕边缘；暖白 #EFEBE5（深色为石墨色，其他配色轻微染色）。当前分类的每一项 = 屏幕中部活动行上的一块档案槽，其余为装饰，项少时循环。
  - 选中项绕近端底边竖起成板，邻项按距离衰减抬升，切换后有向外传播的波浪；上下滑动或 ↑ ↓ 切换（循环，ArchiveSnap 弹簧）。
  - 整个阵列一次 `drawVertices`（预分配顶点 / 颜色缓冲，逐帧零分配，动画值只在绘制阶段读取）。
  - HUD：左上「IRIDIS / ARCHIVE」、排序菜单与新建文件夹；中右路径（可点）、FILE NUMBER: F-001（滚动数字）、带方点的细线、名称（系统项带「系统」）、打开 ACCESS FILE →；左下 ARCHIVE / SELECT 大号计数 01 / 06 与刻度尺；底部 ← COLUMN 01/03 → 分类切换（文件夹 / 文档 / 媒体 / 模型 / 其他，空分类跳过）；底部等宽小字：大小 · 修改时间、根路径。HUD 后有渐变遮罩保证可读，背景档案槽上不绘制文字。
  - 打开文件夹：档案槽躺下、阵列滑动一行、新文件夹的档案槽依次竖起；打开文件：解密详情——磨砂玻璃板（螺丝点、IRIDIS · NO.001 标签、淡圆环；图片文件显示缩略图），斜线扫过再收拢、由上而下磨砂变清晰；字段先显示为黑条再自左向右退去；01 概述 / 02 预览（文本 / Markdown）；黑色操作条 打开 / 分享 / 重命名 / 删除（遵守 canRename / canDelete）。竖屏玻璃板在上（约 40% 高）。返回时档案槽重新竖起。长按竖起的档案槽 = 原操作菜单。
  - 每次启动首次进入时播放约 700ms 白色开场（左上 IRIDIS / ARCHIVE DATABASE），随后阵列淡入落定。
  - 移除动画：无开场、竖起、波浪、解密，直接显示最终状态。
- 「卡片」（CardStackFileView，原卡组）：整组卡片垂直居中（不再空出上半屏）；卡片不透明，只有聚焦卡绘制文字（滚动半张卡内淡出），不再透字。
- 几何（投影、阵列布局与遮挡顺序、竖起 / 抬升 / 波浪、循环、分类分组、编号 / 计数格式、解密进度）在 `ArchiveMath`，新增 ArchiveFieldTest；FilesLogicTest / V219ReleaseTest 更新。
- 未真机验证新「档案」的观感与帧率；无 Robolectric / Paparazzi，仅 JVM 单测（可用 IRIS_ARCHIVE_PREVIEW 输出平面着色预览图）。
