# 发版前真机冒烟清单

每个正式版（非 beta）发布前，在至少一台真机上走完；任一项失败不发版。结果贴到 Release 说明末尾（机型 + 通过项）。
没走完的版本，Release 标题标「未真机测试」，并只发 pre-release。

| # | 项 | 通过标准 |
|---|----|----------|
| 1 | 覆盖安装上一版 | 不闪退；对话、模型、设置都在 |
| 2 | 加载 GGUF（CPU） | 小模型（≤2B）加载成功，能连续回复 3 轮 |
| 3 | 加载 GGUF（GPU / NPU，机器支持时） | 「实际后端」显示正确；失败能回落 CPU，不闪退 |
| 4 | 识图 | 带 mmproj 的模型能描述一张图片 |
| 5 | 智能体写文件 | 让模型在 workspace 新建文件，确认弹窗出现，文件存在 |
| 6 | 生图（机器支持时） | 生成一张 512px 图，无闪退 |
| 7 | 语音 | 语音输入转文字；朗读一段回复 |
| 8 | 本地 API | `curl 127.0.0.1:<端口>/v1/models` 返回模型列表 |
| 9 | 下载 | 下载一个小模型，中途断网再恢复，能续传并完成 |
| 10 | 本版新功能 | CHANGELOG 里本版每一条至少点一次 |

备注：MTP / DSpark、LES、NPU 等依赖芯片的功能，写明测的是哪颗芯片。
